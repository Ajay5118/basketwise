# BasketWise MVP

Privacy-first INR expense tracking from user-supplied receipts. The first acceptance flow is upload a synthetic Instamart PDF, review extracted items and fees, explicitly supply missing date, confirm, and see ₹286 in confirmed spending. No receipt becomes an order before confirmation. Unknown values remain null. Derived unit prices carry provenance.

Users register with processing consent, import PDFs/images, correct drafts, inspect orders, view spending, import bank alerts, export and delete their account. Cancelled orders and unlinked payments are excluded from spending; only confirmed refunds reduce spending. Email integration remains disabled.

Platform fixtures are synthetic and establish only their tested format, never general platform compatibility. Real receipt coverage is required before broad support claims.

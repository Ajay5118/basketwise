# Implementation plan

1. Foundation: Django configuration, models, migrations, JWT and API contract; Flutter shell.
2. Vertical slice: validated upload, asynchronous PDF/OCR extraction, editable preview, atomic confirmation, confirmed-spend dashboard.
3. Tracking: synthetic parser variants, history and corrections, refunds, bank alerts, analytics and export.
4. Quality: isolation, malicious input, reconciliation and idempotency tests; Flutter analysis/tests; deployment and Android instructions.
5. Deferred: real receipt corpus, genuine consented OAuth integrations and notification feasibility, after verified core flow.

Verification evidence and runtime limitations are recorded in README. No unavailable runtime is counted as tested.
